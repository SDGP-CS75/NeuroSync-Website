Support and release notes.

Installation help, beta requirements, known limitations, and the best way to report a problem.

Android beta requirements

  • An Android phone or tablet with a current web browser.
  • About 100 MB of free storage for the download and installation.
  • Permission to install an app from your browser.

How to install the beta

  1. Open the download section on the NeuroSync home page.
  2. Download the APK on the Android device where you want to use NeuroSync.
  3. When Android asks, allow installs from your browser.
  4. Open the downloaded file and confirm the installation.

If installation fails

Confirm that the download finished, free up storage, and remove any older NeuroSync test build before trying again. Android may show a Play Protect warning because this beta is not distributed through Google Play. Only continue if the APK came from the official NeuroSync site.

If the download link has expired, request a fresh beta build through the project issue tracker.

Report a problem

Open a beta feedback issue and include:

  • Your device model and Android version.
  • The steps that led to the problem.
  • What you expected and what happened instead.
  • A screenshot only if it contains no personal or health information.

GitHub issues are public. Do not include passwords, health records, or other sensitive information. For a privacy question, describe the issue without posting personal data first.
